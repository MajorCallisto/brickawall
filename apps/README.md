# apps

Application packages live here, one folder per app. The project is structured as a monorepo so that shared packages can be added later without moving code.

| App | Description |
|-----|-------------|
| [`runWallApp`](./runWallApp/README.md) | The runWall web application: Next.js, react-three-fiber, Tailwind, zustand, zod, Drizzle on Neon, Sanity, Veil Mail |

Run from the repo root with `pnpm dev`.
